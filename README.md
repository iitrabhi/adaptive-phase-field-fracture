# SPICE

Scalable Phase-field Implementation of Crack Evolution (SPICE) for Modeling Surface Crevasse Growth and Interaction in Glaciers.

The archive includes mesh files used in all numerical experiments presented in the paper

Reproducibility
The simulations are based on a phase-field fracture formulation implemented in FEniCS. A non-adaptive baseline implementation of the SPICE framework is publicly available on GitHub and serves as the foundation for the results presented here. The adaptive mesh refinement capabilities described in the manuscript are developed as research extensions on top of the baseline code.

The provided mesh and input files are sufficient to reproduce the reported results using the baseline code and the methodological details described in the paper. Due to the research-stage nature of the adaptive framework, the full adaptive implementation is not publicly released at this time.

Usage
Users may reuse the data and meshes for research and validation purposes, with appropriate citation of the associated manuscript and this Zenodo record.
